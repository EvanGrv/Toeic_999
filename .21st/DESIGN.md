# TOEIC 990+ AI — design

Espace de travail calme pour un adulte préparant un score élevé. Vert forêt, surfaces blanches, fond ivoire, accents sauge et sable. Le bloc du jour porte une typographie éditoriale ; le reste privilégie la lisibilité et la densité raisonnable.

Règles : aucun faux score de progression ; états vides explicites ; une action principale par section ; réponses sélectionnées, correctes et incorrectes avec indices textuels ; navigation mobile accessible ; focus visible et mouvement réduit.

La recherche 21st a identifié [Skills Progress Dashboard](https://21st.dev/@shadcnspace/components/progress-03) et [App Dashboard Layout](https://21st.dev/@shadcnstore/components/app-1). Aucun code n’a été importé. Les primitives du projet sont locales.
