# Médias du projet

L’image `public/images/workplace-atlas.png` est une création de synthèse originale produite avec le générateur Imagegen intégré, puis copiée dans le projet. Aucun fichier distant n’est nécessaire à l’utilisation. L’atlas 1536 × 1024 comporte six cases sans gouttière, trois colonnes et deux lignes. Le cadrage est effectué en CSS.

Brief de reproduction : six photographies réalistes de situations professionnelles et quotidiennes, clairement séparées en grille régulière : salle de réunion vide avec des chaises autour d’une table ; employé d’entrepôt poussant un chariot de cartons ; barista versant du café ; voyageurs sur un quai ; ordinateur portable et pile de livres sur un bureau ; jardinier arrosant des fleurs. Aucun texte ni marque. Les descriptions des questions doivent rester cohérentes avec les détails effectivement visibles.

Les voix sont synthétisées localement avec macOS (`say`) : Samantha, Daniel, Karen et Moira. L’étiquette d’accent indique la voix dominante ; certains dialogues mêlent plusieurs accents. Le script `scripts/generate_audio.py` contrôle la présence d’échantillons non nuls avant d’écrire le manifeste des durées.

Ces images et audios sont destinés à la préparation personnelle ; ils ne proviennent pas d’un examen ETS. La Partie 1 contient six photos réutilisées dans les huit séries.
