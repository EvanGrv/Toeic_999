## Choix de production

Les questions présentes sont originales. La banque initiale comporte 236 questions ; l’extension comporte 2 108 variantes paramétrées. Leurs énoncés, chiffres, options et corrections sont construits ensemble, avec une provenance `variant_family`.

Les huit séries complètes suivent les comptes du format classique. Les séries 02–08 reprennent des **familles de situations**, et les six photographies sont communes. Huit séries ne signifient donc pas huit examens éditorialement indépendants ou officiels.

Les images ont été créées pour ce projet via Imagegen ; les voix locales sont produites avec les voix macOS présentes sur la machine. Ces audios sont des supports personnels d’entraînement, pas des enregistrements ETS.

## Import et croissance

L’atelier accepte une question de partie 5 au format JSON, avec déclaration de droits. Un import est un brouillon. La publication requiert une relecture explicite. Le générateur local crée des variantes grammaticales ; le générateur OpenAI optionnel fait deux appels, dont une résolution sans clé fournie. Les vérifications structurelles et la concordance des deux réponses ne garantissent pas à elles seules une qualité d’examen.

Pour utiliser ultérieurement un livre ou une banque achetée, vérifier l’autorisation d’adaptation et d’intégration ; l’achat d’un accès individuel n’établit pas ce droit. Il reste possible de travailler directement chez l’éditeur via les liens proposés.
