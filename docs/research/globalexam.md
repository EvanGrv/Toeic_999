# GlobalExam — exploration publique

Consultation : 13 octobre 2026. Source principale : [page TOEIC](https://global-exam.com/fr/exam/toeic).

| Fonction | Évidence publique | Limite |
|---|---|---|
| Navigation | Certifications, langues générales, anglais professionnel, tarifs, blog | Interface connectée non explorée |
| Parcours | Personnalisation annoncée selon objectif et date | Algorithme non visible |
| Entraînement | Exercices avec corrections détaillées annoncés | Exécution non testée |
| Examen | Examens blancs chronométrés annoncés | Aucun test lancé |
| Cours | Fiches de grammaire, vocabulaire et expression | Profondeur non vérifiée |
| Statistiques | Suivi personnalisé annoncé | Dimensions internes non accessibles |
| Coaching | Vidéos et cours avec enseignants annoncés | Certaines offres réservées aux abonnements |
| Offres | Basic, Premium, Premium Plus mentionnés | Montants non vérifiés |
| Révision adaptative | Parcours sur mesure visible dans la présentation | Répétition espacée précise non démontrée |

Le site public permet d’identifier la proposition pédagogique, pas de prouver son efficacité ni de reproduire son interface interne. Les témoignages et gains affichés restent des affirmations de l’éditeur. L’essai renvoie à l’authentification ; aucune inscription effectuée.

Application concrète : associer objectifs, planning, cours, exercices et bilan. Les paramètres ne doivent pas figer le parcours : les réponses observées déterminent ensuite les priorités. Les corrections et contenus du projet sont originaux.
